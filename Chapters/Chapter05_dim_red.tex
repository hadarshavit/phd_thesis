\section{Introduction}
\label{sec:ch05:intro}
High-dimensional data is ubiquitous in numerous application domains of machine learning and black-box optimisation.
% ~\citep{}.
% \er{Should we add references here?} 
In areas ranging from computer vision~\citep{SchEtAl15}, genome sequencing~\citep{VanEtAl22} and anomaly detection~\citep{TalEtAl21} to engineering~\citep{PreEtAl24}, hyperparameter optimisation~\citep{SehEtAl22} and neural architecture search~\citep{ElsEtAl19}, complex datasets with a large number of features defining 
%\hh{modified:}
a space to be searched for desirable design choices or solutions 
need to be handled effectively, in order to ensure that machine learning and  black-box optimisation algorithms applied to them are as accurate, efficient and scalable as possible. 
This poses a fundamental challenge in many applications, due to the curse of dimensionality, where the volume of the search space grows exponentially as data dimensionality increases, thereby degrading the performance of an algorithm applied to that data.
Data points become sparser in high dimensions, making it difficult for a machine learning algorithm to capture the underlying structure of the data and for a  black-box optimisation algorithm to locate good solutions for a given problem. 
At the same time, computational complexity severely increases, as well as the risk of overfitting in machine learning applications, leading to poor generalisation ability.

Dimensionality reduction methods serve as a crucial tool to address the challenge of manipulating high-dimensional data by evaluating the available information and extracting essential features from it.
% thereby enabling enhanced scalability of the models. 
The core principle of dimensionality reduction is to transform data from a high-dimensional space to a lower-dimensional one, revealing the underlying 
% low-dimensional 
structure that is concealed in the original
% high-dimensional 
data. 
% A general property of dimensionality reduction methods is the ability to preserve essential knowledge about the original data. 
Operating in a low-dimensional space enables machine learning algorithms to capture meaningful patterns in the data and  black-box optimisation algorithms to search for an optimal solution more effectively.
Traditionally, dimensionality reduction is used for machine learning tasks to reduce the input size of the data, as many machine learning algorithms (such as random forests~\citep{Breiman01} and support vector machines~\citep{CorVap95}) scale poorly with the number of features 
% \hh{added:}
in terms of computational complexity. 
Dimensionality reduction methods are also employed for data clustering and visualisation~\citep{VanHin08}.
For classical applications, good performance of machine learning algorithms heavily relies on the ability of dimensionality reduction methods to preserve essential 
% \hh{modified:}
information contained in the data.
In the context of machine learning, this leads to higher interpretability of the models, reduced 
% \hh{modified:}
time and space complexity, less overfitting, and ultimately improved generalisation performance of machine learning models~\citep{JiaEtAl22}.

The curse of dimensionality is also a major obstacle for solving optimisation problems~\citep{Garnett23}. 
% \changed{
High-dimensional optimisation problems are widely encountered in the field of machine learning; for instance, the performance of machine learning algorithms crucially depends on the chosen values of the hyperparameters that govern their behaviour, and the performance of neural networks on some task of interest is heavily impacted by the choice of its architectural components~\cite{ElsEtAl19}.
Finding a well-performing set of hyperparameter values or a well-suited neural architecture for a given problem are  black-box optimisation problems, typically high-dimensional and expensive to evaluate.

% \hh{minor rewording:}
Typically, as the dimensionality of the search space increases, the volume grows exponentially, making it progressively more challenging for these algorithms to effectively locate good solutions. They also take more time to run in high-dimensional spaces.

In this context, dimensionality reduction methods have the potential to facilitate the optimisation process by transforming the high-dimensional problem landscape into a lower-dimensional one that may well be easier to tackle. 
We argue that preserving essential information about the data might not be imperative in the context of  black-box optimisation tasks (at least not in the way required for machine learning) if the performance of the optimisation algorithm is enhanced by navigating a more tractable landscape (assuming we are able to adequately reconstruct in the original space the points corresponding to the high-quality solutions

Feature selection determines a subset of individual features from a given, larger set, such that irrelevant, redundant, or noisy features are eliminated~\citep{TheBho24}.

\changed{Feature extraction, which we consider in the remainder of this study, creates new features from the original ones through linear or non-linear mappings~\citep{ElhEtAl24}. This process can enhance separability and represent information shared across multiple original features, making it possible to reduce dimensionality with limited information loss.}

\subsection{Related work}
\label{sec:ch05:rel-work}

% \changed{
% \er{Why does this come now only? Shouldn't it follow the Intro?} 
% \aj{changed the order}
\changed{
As dimensionality reduction plays an essential role across a wide range of applications, numerous studies have surveyed and compared dimensionality reduction methods from different perspectives. In the following, we present such prior work, distinguishing between publications 
% \hh{slightly modified:}
that focus on surveying existing methods and theoretical analyses and those that provide empirical comparisons.

We begin with surveys and theoretical analyses.
The early overview by~\citet{Fodor02} presented a survey of dimensionality reduction methods, distinguishing between linear and non-linear approaches. \citet{LeeVer07} organised non-linear dimensionality reduction methods according to intrinsic dimensionality, distance preservation and topology preservation, and included explicit method comparisons, while~\citet{Burges10b} separated the methods into projective methods and methods that model the manifold on which the data lies. \citet{SorEtAl14} categorised the methods as based on statistics, dictionaries and mappings, followed by a discussion on trends in their usage. 
For linear methods,~\citet{CunGha15} reviewed various techniques ranging from PCA and factor analysis to supervised mappings, formulating them within a unified optimisation framework over matrix manifolds; they analysed the relationships and similarities among these techniques, highlighting previously overlooked limitations. 
Complementing this view,~\citet{ChaEtAl19} focussed specifically on supervised reduction, classifying methods according to PCA-, NMF-, and manifold-based constructions and analysing their respective advantages and disadvantages. 
The recent statistical review by~\citet{MeiZha24} concentrated instead on the assumptions, theoretical guarantees, and parameter choices underlying manifold learning. \citet{TjEtAl23} reviewed statistical embeddings beyond PCA, covering non-linear, manifold, topological, network and visual embeddings. Finally, the tutorials by~\citet{GhoEtAl20,GhoEtAl21} traced the stochastic-neighbour-embedding family and the development of UMAP into supervised, parametric, density-preserving, and streaming variants.
}

\changed{
Other surveys organised dimensionality reduction methods according to their practical applications and the criteria used to evaluate their outputs.
\citet{EngEtAl11} reviewed point-based mappings for exploratory analysis and visualisation;~\citet{NonAup19} related mapping families to the distortions they introduce, the visual analysis tasks they support, and mechanisms for exposing those distortions;~\citet{JeoEtAl25} developed a taxonomy of challenges related to reliability of dimensionality reduction-based visual analytics, while discussing mapping distortions, evaluation, interpretation and practical analytical workflows. 
Broader surveys by~\citet{AyeEtAl20}, \citet{RayEtAl21}, and~\citet{JiaEtAl22} compared linear and non-linear techniques, their application domains, computational characteristics, and suitability for different data types. Together, these surveys make it clear that methods preserve different properties and that visual or geometric fidelity is not interchangeable with utility for a subsequent learning or optimisation task.
}

\changed{
Beyond these literature surveys and taxonomies, several studies presented controlled empirical comparisons of multiple dimensionality reduction methods.
The comparative review by~\citet{VanEtAl09} evaluated PCA and twelve non-linear methods on synthetic and real-world datasets, measuring the generalisation error of 1-nearest-neighbour classifiers together with trustworthiness and continuity of the low-dimensional embeddings.
% using reconstruction and nearest-neighbour generalisation to expose weaknesses of the resulting representations. 
\citet{EspEtAl21} benchmarked 44 dimensionality reduction techniques on 18 machine learning datasets, using seven quality metrics that assess neighbourhood preservation, class separability, and geometric distortions, while additionally examining computational efficiency and the effects of hyperparameter choices; however, these quantities characterise the dimensionality reduction method itself rather than the performance in a downstream task supported by dimensionality reduction, which is a crucial difference to our work.
% these quantities characterise the embedding itself rather than the performance of a downstream predictor or optimiser. 
\citet{WanEtAl21} compared t-SNE, UMAP, TriMap, and PaCMAP through controlled changes to their attraction--repulsion mechanisms and measured local and global structure preservation. 
In a transcriptomic setting,~\citet{HuaEtAl22b} evaluated eight modern dimensionality reduction methods with respect to local and global structure, their sensitivity to parameters and preprocessing, and computational efficiency; in particular, to indicate local structure preservation, they evaluate the accuracy of support vector machines and $k$-nearest-neighbours on low-dimensional representations.
However, their primary objective is assessing the trustworthiness of low-dimensional visualisations in transcriptomics, making it crucally different from ours, which is evaluating the performance in downstream classifiers across multiple target dimensionalities and tasks.
\citet{TiaEtAl21} complemented quantitative mapping measures with a user study comparing two- and three-dimensional outputs from 29 techniques. Focusing on downstream classification,~\citet{AnoEtAl21} compared ten linear and non-linear feature extraction algorithms on three datasets in terms of accuracy and speed, while~\citet{SubEtAl24} evaluated four low-cost reduction methods on ten datasets and seven classifiers, considering predictive performance together with time and memory. Domain-specific benchmarks covered narrower settings, including drug sensitivity prediction~\citep{EckEtAl24}, multi-omics analysis~\citep{CanEtAl21}, microbiome data~\citep{ArmEtAl22}, and image retrieval~\citep{ZhuEtAl14}. Most closely related to Task~3 (target function approximation),~\citet{HouBeh22} reviewed combinations of dimensionality reduction and surrogate models, cataloguing their mathematical properties, applications, and limitations rather than evaluating a common set of reducers under a controlled protocol.
}

\changed{Comparative studies have also been conducted when new dimensionality reduction methods are introduced, although these evaluations tended to follow a recurring, yet narrower, pattern. t-SNE was compared with seven preceding non-parametric techniques on five datasets, primarily through two-dimensional maps~\citep{VanHin08}. LargeVis and UMAP subsequently treated t-SNE as the principal contemporary baseline, with comparisons focusing on the preservation of visual structure, scalability, and running time; UMAP~\citep{McIEtAl18} additionally included linear and spectral references and examined stability. More recent extensions often compare directly with their parent method on the property they are designed to improve: densMAP~\citep{NarEtAl21} measures density preservation against UMAP and t-SNE, while \hs{the evaluation of parametric UMAP~\citep{SaiEtAl21} compares it with parametric t-SNE and autoencoders under controlled neural architectures and optimisers, and reports results on trustworthiness, classification accuracy, reconstruction, and embedding time.}
%\hh{who? UMAP? (wording issue)}
 PaCMAP and LocalMAP~\citep{WanEtAl21,WanEtAl25} have been similarly evaluated against contemporary neighbour-embedding methods, using local and global structure scores. Thus, new methods have been commonly judged against an immediate predecessor, and a small set of currently popular visualisation methods, usually for two-dimensional embeddings and often with method-specific quality criteria. These studies established whether the proposed mechanism improves its intended property, but \hs{did} not show whether the same advantage transfers to higher-dimensional representations and heterogeneous downstream tasks.

Finally, we note that even when dimensionality reduction techniques have been assessed in prior work in terms of their performance on downstream tasks, these tasks commonly belong to (unsupervised or supervised) learning, either in a controlled benchmark environment or in a specific domain of real-world application. Yet another important use-case of dimensionality reduction techniques exists in the domain of optimisation, in particular for, but not limited to, assisting Bayesian optimisation in high-dimensional spaces. In this work, we present an in-depth overview of related work along the axis of dimensionality reduction in optimisation in~\cref{app:ch05:rel-work-dr-opt}.}

\changed{
The aforementioned empirical comparisons leave open questions that motivate this study. 
Dimensionality reduction is typically studied within a single task family, using either measures of the embedding itself or a single downstream learning task.
Therefore, it is unclear whether the ranking of the methods remains invariant when considering optimisation instead of learning tasks, and whether a representation that allows for accurate prediction of function values also allows for an effective sequential search process.
Additionally, previous studies have often focussed on two- or three-dimensional embeddings, rarely examining how the amount of training data affects the performance of dimensionality reduction methods. The latter, however, is very relevant for sample-efficient black-box optimisation, which requires representations with moderate dimensionality, often learned from as few as a hundred observations. Moreover, in the optimisation literature, dimensionality reduction has been usually developed together with a specific optimiser (see~\cref{app:ch05:rel-work-dr-opt}), which makes it difficult to separate the contribution of the learned representation from that of the search procedure.
}

    \noindent \textbf{Principal component analysis with linear kernel (PCA Linear)}~\citep{Pearson1901} is an unsupervised linear method equivalent to standard PCA, where the linear kernel is defined as the dot product between data vectors. The kernel matrix captures the pairwise similarities between data points based on their linear relationships in the original space, \emph{i.e.,} the original space does not undergo any transformation. The eigenvectors of the kernel matrix correspond to the principal components in the original space, and the eigenvalues represent the explained variance along each component. Put differently, PCA seeks to find the directions of maximum variance in the data covariance matrix, assuming they correspond to the most informative dimensions. PCA is especially useful for structured, linear data, but in the default implementation comes with a substantive computational overhead due to computing and storing the full kernel matrix, making it hard to use for large datasets. 
    % All subsequent variants of PCA with different kernels suffer from similar computational and memory limitations in their default implementations.
    
    \noindent \textbf{Principal component analysis with cosine kernel (PCA Cosine)}~\citep{SchEtAl97} is a variant of kernel PCA that uses a cosine kernel instead of a linear kernel in order to capture non-linear relationships in the data. The cosine kernel focuses on angular relationships between data vectors rather than their magnitudes. It measures cosine similarity based on vector orientation, with values ranging from identical directions, over orthogonality, to opposite directions. Vector magnitudes are only used to normalise the data, projecting all data points onto the unit hypersphere before computing similarities. The fact that PCA with cosine kernel preserves only angular variance of the data makes it particularly effective for high-dimensional data where directional patterns are more meaningful than absolute values. 
    % PCA with cosine kernel in the default implementation suffers from similar computational and memory limitations as the standard PCA. 
    
    \noindent \textbf{Principal component analysis with polynomial kernel (PCA Poly)}~\citep{SchEtAl97} is a variant of kernel PCA that captures non-linear polynomial relationships in the data by implicitly mapping the data to a higher-dimensional space where polynomial feature interactions become explicit. The polynomial kernel is a positive definite kernel that computes similarities based on polynomial relationships between all pairs of data points. The eigendecomposition of the kernel matrix yields the principal components in the polynomial feature space, which capture directions of maximum variance among the polynomial feature combinations. This enables PCA to find curved, non-linear principal components in the original space, making it suitable for data with inherent global polynomial structure. 
    % Similarly to default implementations of other PCA variants, it also suffers from computational and memory limitations.
    
    \noindent \textbf{Principal component analysis with radial basis function kernel (PCA RBF)}~\citep{SchEtAl97} is a variant of kernel PCA that captures complex, non-linear relationships in the data by implicitly mapping the data to a higher-dimensional space where feature similarities are based on Euclidean distances. The RBF (also known as Gaussian) kernel is a positive definite kernel that measures similarity based on proximity in the original space. Unlike polynomial kernels that capture global algebraic relationships, RBF kernels focus on local patterns. The resulting principal components (obtained via the eigendecomposition of the kernel matrix) are non-linear functions of the original coordinates, able to follow curved paths through the data points; they capture the most significant non-linear variations in the data, assuming that they are smooth and continuous. This allows for the detection of complex, curved manifolds, spiral patterns and localised structures in the original space, and makes PCA with RBF kernel effective for datasets with inherent geometric structure. 
    
    \noindent \textbf{Principal component analysis with sigmoid kernel (PCA Sigmoid)}~\citep{SchEtAl97} is a variant of kernel PCA that employs a sigmoid (hyperbolic tangent) function to create a feature space which emphasises threshold-like relationships in the data. The sigmoid kernel computes similarities based on a tanh transformation of the linear dot product between data vectors, but it is not guaranteed to be positive definite at all times. The feature space mapping of the sigmoid kernel, unlike other kernel PCA methods, captures both positive and negative relationships between data points, and is not distance-based, thereby modelling transition regions rather than smooth polynomial curves. 
    The tanh transformation introduces non-linearity while maintaining sensitivity to both the magnitude and direction of the linear dot product. The eigendecomposition of the kernel matrix yields principal components in the sigmoid feature space, which capture decision boundary- and threshold-like structures in the original data. This makes PCA with sigmoid kernel particularly suitable for data where relationships involve step-like changes or sigmoid curve-shaped transitions between different data regions, states or classes.
    
    \noindent \textbf{Incremental principal component analysis (Incremental PCA)}~\citep{RosEtAl08} is a memory-efficient PCA variant that works similarly to PCA with linear kernel, but allows mini-batch processing, updating principal components as new data becomes available. The covariance matrix is updated incrementally using rank-one updates, and the corresponding eigendecomposition can be maintained without recomputing from scratch. Incremental PCA is suitable for evolving data distributions, data streams, and other non-stationary environments.
    % \item Sparse PCA~\citep{TipEtAl00} is a PCA variant that incorporates sparsity constraints to produce principal components with many zero coefficients, thereby enhancing interpretability. Sparse PCA is also more robust to noise compared to standard PCA, since irrelevant variables are explicitly excluded from components. It excels in high-dimensional settings where interpretability is crucial.
    
    \noindent \textbf{Fast independent component analysis (Fast ICA)}~\citep{HyvOja00} is a linear method stemming from signal processing, where it is used to separate multivariate signals into statistically independent components. As a dimensionality reduction method, it identifies the most significant independent sources underlying observed data, assuming that observed data is a linear combination (or mixture) of unknown independent source signals. This fundamental assumption of statistical independence of components is stronger than the assumption of uncorrelatedness by PCA-based methods. Fast ICA seeks to maximise non-Gaussianity of the recovered components (thereby achieving independence), which are then most likely to correspond to individual sources. Maximising non-Gaussianity measures (such as kurtosis or negentropy) is done using a fixed-point iteration scheme. The most significant independent components are selected based on their contribution to total variance, their degree of non-Gaussianity, or other domain-specific criteria. They represent different types of underlying source patterns, unlike components in PCA which are ordered based on the explained variance. Fast ICA can reveal patterns that PCA might miss when the underlying sources do not correspond to maximum variance directions. Moreover, components extracted by Fast ICA are interpretable and often correspond to meaningful physical or semantic sources. Fast ICA is therefore good at separating components with different statistical characteristics, and is particularly well-suited for dimensionality reduction in cases where independent generating processes of the data are plausible.

    \noindent \textbf{Locally linear embeddings (LLE)}~\citep{RowSau00} are a non-linear method that preserves local relationships between data points by assuming that high-dimensional data lies on or near a smooth, low-dimensional manifold and expressing each point as a weighted sum of its nearest neighbours. It then computes a low-dimensional embedding by finding coordinates in the lower-dimensional space such that each point can be reconstructed from its neighbours using the same weights as in the high-dimensional space. This ensures that local geometries such as distances and angles are preserved without assuming a global linear mapping. LLE is invariant to rotations, translations, and uniform scaling of the input data, but assumes that the data lies on a single, connected manifold. LLE is particularly well-suited for high-dimensional data visualisation and exploratory data analysis.

    \noindent \textbf{Bernoulli restricted Boltzmann machine (RBM)}~\citep{HinEtAl06} is a probabilistic, neural-network-based method that captures complex, non-linear relationships in binary data. It learns a probability distribution where the hidden layer of a neural network serves as a lower-dimensional representation, performing dimensionality reduction through unsupervised learning. Bernoulli RBM learns to extract features that best reconstruct the original data, similar to an autoencoder but with stochastic binary units. The existence of the latter  makes Bernoulli RBMs particularly suitable for discrete or binary data.
    
    \noindent \textbf{Dictionary learning}~\citep{MaiEtAl09} is a sparse linear representation-based method that performs a sparse encoding of the data using a dictionary $\mathbf{D}$ of size $D\times k$. The transformation happens by multiplying the input vector by the dictionary. The method optimises the dictionary to reconstruct the original data as accurately as possible, in addition to ensuring that the low-dimensional data is sparse using $l_1$ norm. Unlike orthogonal transforms, Dictionary Learning typically uses overcomplete dictionaries where the number of basis vectors in the dictionary exceeds the data dimensionality. The quality of reconstruction depends on how well the learned dictionary captures the essential patterns in the data.
    
    \noindent \textbf{Truncated singular value decomposition (SVD)}~\citep{HalEtAl11} is an SVD-based method that computes only the top $k$ singular values and their corresponding singular vectors, rather than the complete SVD decomposition. Similar to traditional PCA, the directions of maximum variance in the data are preserved, but unlike traditional PCA, it does not centre the data, so it finds directions of maximum variance only for centred inputs. It provides the best possible low-rank approximation to the original data matrix, effectively reducing dimensionality while preserving significant features. It is also computationally efficient, as it works directly with the original data and avoids explicit covariance computation. Truncated SVD is suitable for cases where data matrices are naturally sparse.
    
    \noindent \textbf{Factor analysis (FA)}~\citep{Barber12} is a statistical method that reduces the dimensionality by preserving the common factors of the data. Each data point is assumed to be a linear transformation of the low-dimensional latent factors, with the addition of Gaussian noise. It uses SVD to perform maximum likelihood estimation of the transformation matrix. Unlike PCA, which focuses on variance preservation and treats all variance as meaningful, factor analysis specifically aims to identify underlying constructs that explain correlations in the data. Factor analysis excels in psychological and social science research, as it provides insight into data structures beyond mere dimensionality reduction, offering substantive interpretation of what the reduced dimensions represent.

    \noindent \changed{\textbf{Non-negative matrix factorisation (NMF)}~\citep{LeeSeu00} is an unsupervised linear method that approximates a non-negative data matrix as the product of two lower-rank non-negative matrices. One matrix contains a set of latent basis components, while each row of the other contains the non-negative coefficients needed to reconstruct one observation from those components; these coefficient vectors form the reduced representation. The non-negativity constraint commonly yields additive, parts-based representations that can be easier to interpret than components containing cancellations between positive and negative values. NMF is particularly suitable for non-negative data, such as counts and intensities. To use NMF on data containing non-positive values, we fit a per-feature shift on the training data that makes every feature strictly positive and apply the same shift when transforming unseen observations.
    }

It represents each observation as a mixture of $k$ latent components and each component as a distribution over the original features. Dirichlet priors regularise both sets of distributions, while approximate variational inference estimates the latent component proportions. The vector of component proportions associated with an observation serves as its low-dimensional representation. Although LatentDA can be applied only to non-negative data, we use preprocessing to shift every feature to be strictly positive before fitting and transforming the data.}

    \noindent \changed{\textbf{Uniform manifold approximation and projection (UMAP)}~\citep{McIEtAl18} is a non-linear manifold-learning method that first constructs a weighted nearest-neighbour graph. Each edge weight in this graph represents a graded degree of neighbourhood membership derived from local distances, rather than a binary statement that two observations are or are not neighbours. UMAP then finds low-dimensional coordinates by minimising the cross-entropy between this graph and an equivalent weighted graph in the embedding space. This objective draws pairs together in proportion to their high-dimensional edge weights and pushes sampled non-neighbour pairs apart, thereby balancing local neighbourhood preservation against crowding in the embedding.
    In the supervised variant, feature-space relations are combined with a target graph based on Euclidean distances for regression or class membership for classification.}


    \noindent \changed{\textbf{Parametric UMAP}~\citep{SaiEtAl21} replaces the directly optimised coordinates of UMAP with the output of a neural-network encoder. The nearest-neighbour graph is constructed in the same manner as for UMAP, after which positive graph edges and negatively sampled pairs are used to train the network with the UMAP attraction--repulsion objective. Optimising network parameters rather than one independent coordinate vector per training observation yields an explicit mapping that can efficiently embed unseen inputs. }

    \noindent \changed{\textbf{PaCMAP}~\citep{WanEtAl21} is a non-linear manifold-learning method designed to balance preservation of local and global structure. It constructs three sets of relationships: near pairs representing local neighbours, mid-near pairs connecting observations at intermediate distances, and further pairs representing distant observations. A pairwise objective attracts the first two types and repels further pairs, while their relative weights change during optimisation. Early iterations emphasise global organisation through mid-near and further pairs, whereas later iterations refine local neighbourhoods. This staged procedure mitigates the tendency of methods focussed exclusively on nearest neighbours to distort large-scale relationships.}

    \noindent \changed{\textbf{LocalMAP}~\citep{WanEtAl25} extends PaCMAP by dynamically adjusting its neighbourhood graph during optimisation. High-dimensional distances can be unreliable, particularly when the number of features is large, causing a fixed nearest-neighbour graph to contain connections that are inconsistent with the emerging manifold. LocalMAP uses the current embedding to revisit these relationships and locally modify the graph, allowing the optimisation to correct unsuitable neighbours while retaining the pairwise attraction and repulsion principles of PaCMAP. The method consequently places greater emphasis on faithful local structure without abandoning broader relationships between groups of observations. }

    \noindent \changed{\textbf{ParamPaCMAP}~\citep{HuaEtAl24} is a parametric neighbourhood-embedding method derived from PaCMAP. Instead of optimising one coordinate vector for every training observation, it trains a neural network to map original inputs directly into the embedding space. Parametric neighbourhood methods can preserve broad structure and provide efficient out-of-sample transformation, but ordinary random negative sampling may fail to generate sufficiently informative repulsive examples. ParamPaCMAP therefore identifies hard negatives: observations that are not neighbours in the original space but that the current encoder places close together. Giving these misleading pairs a stronger repulsive loss encourages the encoder to separate them while retaining PaCMAP-style near, mid-near and further pair relationships. This provides a reusable non-linear mapping while seeking to preserve more local detail than conventional parametric embeddings.}

    \noindent \changed{\textbf{Autoencoder}~\citep{Ballard87} is an unsupervised neural-network method composed of an encoder and a decoder. The encoder maps an input through \hs{one or two hidden layers, depending on the variant,} to a bottleneck of dimension $k$, and the decoder reconstructs the original input from this bottleneck using a symmetric architecture. Training minimises mean squared reconstruction error, forcing the bottleneck to retain information that is sufficient to reproduce the observations. After training, only the encoder is needed for dimensionality reduction, and its bottleneck activations form the reduced representation. Unlike PCA, an autoencoder can learn non-linear transformations through its activation functions, although the reconstruction objective does not explicitly preserve neighbourhoods or information relevant to the downstream target.}

    \noindent \changed{\textbf{Denoising autoencoder}~\citep{BenEtAl13} modifies the standard autoencoder by corrupting each training input with Gaussian noise while retaining the clean input as the reconstruction target. The encoder must therefore learn features that are stable under small perturbations rather than simply reproduce each observation through an identity-like mapping. This regularisation can make the bottleneck representation more robust and encourage it to capture the underlying structure of the data. Our implementation uses \hs{either one or two hidden layers in both the encoder and decoder, depending on the variant,} and minimises mean squared reconstruction error between the clean observation and the reconstruction obtained from its noisy counterpart. Transformation of unseen data uses the uncorrupted input and the trained encoder only.}

    \noindent \changed{\textbf{Variational autoencoder}~\citep{KinWel14} is a probabilistic extension of the autoencoder. Its encoder produces a mean and variance for the latent representation of each observation rather than a single deterministic bottleneck vector. A latent vector is sampled through the reparameterisation trick and passed to the decoder. Training combines mean squared reconstruction error with a Kullback--Leibler divergence penalty that regularises the latent distribution towards a standard normal distribution. This encourages a smooth and continuous representation in which nearby latent points decode to similar observations. Our \hs{one- and two-hidden-layer variants use} the encoder mean as the deterministic $k$-dimensional representation when transforming data.}
% \hh{is the restriction to one layer something one should be worried about? can we point to the literature to justify this choice?}}
    \noindent \changed{\textbf{Slipmap}~\citep{BjoEtAl24} is a supervised manifold method that jointly constructs a low-dimensional embedding and a collection of interpretable local models. Prototype observations are associated with local linear or logistic models, and the objective encourages nearby embedded observations to share models that predict their targets accurately. Regularisation of the local coefficients limits spurious explanations and promotes a smoother, more robust representation. Slipmap is a scalable prototype-based development of Slisemap~\citep{BjoEtAl23},

reducing the number of local models that must be fitted while retaining the link between embedding proximity and similarity of local explanations. }

Point coordinates are then rescaled in such a way that points with a poor function value are pushed towards the origin and have less impact during the training of the feature extraction mapping.
Let $\{r_i\}_{i=1}^N$ be the ranking of the points in $S$ according to their function values $y$. The weights are computed as $w_i = \ln{N} - \ln{r_i}, \forall i=1,\dots,N$ and then normalised to form the weight vector $W$.

We rescale the original data $S$ by removing its sample mean, \emph{i.e.}, $\bar{S} = S - \mathbf{1}_N\mu$, where
$\mu$ is the centre of mass of the sample and $1_N$ is the all-ones vector of size $N$.
We then adjust each point with the corresponding weight, namely, $S' = \bar{S}W$.
For each of the unsupervised feature extraction methods that we benchmark, the initial sample on which they are trained first undergoes the rescaling. This means that the mapping is first learned on $S'$, and then applied to the centred sample $\bar{S}$.

\section{Related work on dimensionality reduction in optimisation}
\label{app:ch05:rel-work-dr-opt}
% \changed{
Bayesian optimisation in high-dimensional spaces has also received considerable attention in recent years. \changed{\citet{BinWyc22} have surveyed the structural assumptions used in high-dimensional Gaussian-process modelling and Bayesian optimisation, including variable selection, additive decomposition, and low-dimensional embeddings, and have noted that these assumptions commonly require corresponding changes to acquisition-function optimisation.}
Numerous methods have been proposed to address the curse of dimensionality.
REMBO~\citep{WanEtAl16b} exploits the assumption that high-dimensional objective functions often have low effective dimensionality by optimising within random low-dimensional subspaces.
Linear embedding approaches such as ALEBO~\citep{LetEtAl20} learn low-dimensional representations of the search space through adaptive coordinate transformations. 
Trust-region methods like TuRBO~\citep{EriEtAl19b} decompose the optimisation problem into local subproblems that are easier to solve in high dimensions.
BAxUS~\citep{PapEtAl22} employs axially aligned subspaces to reduce dimensionality while maintaining interpretability, while BOIDS~\citep{NgoEtAl25} exploits additive structure in the objective function. 
Random projection methods such as RPM-BO~\citep{NguTra24} leverage the Johnson-Lindenstrauss lemma to perform optimisation in randomly projected subspaces. 

\changed{
Dimensionality reduction has also been investigated outside Bayesian optimisation. 
In neuroevolution,~\citet{RakEtAl21} proposed learning a low-dimensional representation of neural-network policy parameters and conducting quality-diversity search in the resulting latent space.
Related approaches have also used PCA and kernel PCA in evolutionary optimisation, to support covariance adaptation, surrogate modelling, and computationally demanding engineering design~\citep{MeiWan21b,KapEtAl16,AbbEtAl20}.
More broadly,~\citet{HonEtAl21} and~\citet{TiaEtAl21b} surveyed evolutionary approaches for large-scale multi-objective optimisation, including dimensionality reduction, decision-variable grouping, and decomposition strategies.
\citet{ZhoEtAl24} further reviewed evolutionary optimisation methods for high-dimensional problems with expensive objective evaluations. Unlike our study, these works primarily investigate integrated optimisation methods or families of algorithms rather than systematically comparing general-purpose feature extraction methods under a fixed downstream optimisation procedure.
% the broader large-scale optimisation literature additionally includes decomposition, variable grouping, and reduced-search-space strategies. These approaches and the high-dimensional Bayesian optimisation methods above are generally integrated algorithms in which the representation and search procedure are designed together. In contrast, this work does not propose a new optimiser, but isolates the effect of applying different reusable feature mappings within a fixed Bayesian optimisation pipeline.
}
% }

% To the best of our knowledge, no comprehensive benchmarking study exists that assesses and compares a wide range of inherently different dimensionality reduction methods simultaneously in the context of machine learning and black-box optimisation.
\changed{Here, we emphasise that, despite substantial work on specialised high-dimensional optimisation algorithms, a broad task-level comparison of general-purpose dimensionality reduction methods within the same black-box optimisation pipeline remains missing.}
Along these lines,~\citet{RapEtAl25} showed that global sensitivity analysis, when used as a dimensionality reduction technique, might oversimplify the landscape of the optimisation problem at hand, which renders it poorly suitable for these purposes. 
At the same time, they emphasise the importance dimensionality reduction methods might have in the optimisation context.

\section{Results with tuned dimensionality reduction methods}
\label{app:ch05:tuned-results}

\changed{
In addition to the main experiments which use the default hyperparameter settings for each considered dimensionality reduction method, here we assess
}
% We additionally assess 
whether task-specific hyperparameter optimisation changes the relative performance of the dimensionality reduction methods. Due to the computational cost of tuning, we focus on the 24 synthetic BBOB functions with \(N=100\), \(k=10\), and \(D\in\{120,240\}\) for the black-box optimisation tasks. For the machine learning tasks, we consider \(k\in\{5,10,20,40\}\).

\subsection{Setup of experiments}
\label{app:ch05:cs}
\label{app:ch05:tuning-protocol}

We tune dimensionality reduction hyperparameters with SMAC3 using 30 trials, a deterministic scenario, and random seed 0. Each trial evaluates one candidate in parallel on up to 24 functions or datasets. Reducers without a hyperparameter in \cref{tab:ch05:reducer-cs-classical,tab:ch05:reducer-cs-nonlinear} retain implementation defaults: PCA (Linear), PCA (Cosine), incremental PCA, truncated SVD, LoLP, PLS regression, factor analysis, and Gaussian and sparse random projections.

For target function approximation and Bayesian optimisation, one configuration is learned per method, input dimensionality, and target dimensionality, shared by all BBOB functions. Tuning uses instance 100 for each of the 24 functions. The target function approximation objective is mean three-fold inner-CV RMSE from a random forest with 64 trees and feature fraction 0.5. The Bayesian optimisation objective is mean base-10 logarithmic final simple regret after 300 evaluations. Final evaluation uses instances 0--30 and, for target function approximation, five outer folds.

For machine learning, OpenML tasks 12, 28, and 43 are used only for tuning. Ten tasks sampled with seed 0 from the remaining eligible tasks are used for testing: 16, 9946, 10090, 14952, 14954, 146817, 146824, 359958, 359967, and 359970. Prediction configurations are tuned separately for each reducer, \(k\), and classifier family by maximising mean accuracy. Clustering runs two independent SMAC optimisations per reducer and \(k\), maximising homogeneity and completeness separately. Tuning uses fold 0; final evaluation uses every available fold of the held-out tasks.

In the domains below, \emph{log} indicates logarithmic sampling, \(N\) is the initial sample size for reducer training, and \(k\) is target dimensionality.

\section{Task 4: Bayesian optimisation using the reducer training sample}
\label{app:ch05:bop-initial-sample}

\changed{
The main Bayesian optimisation experiments used a separate 30-point Sobol design to initialise the Gaussian process after fitting the dimensionality reduction method on \(N\) points. We additionally evaluated a reuse strategy in which the same \(N=100\) Sobol points used to fit the reducer also initialise Bayesian optimisation. This avoids an additional initial design and allows all reducer-training observations to inform the first surrogate. Under the fixed budget of 300 function evaluations, the reuse variant begins with 100 observations and performs 200 adaptive steps, whereas the main variant begins with 30 observations and performs 270 adaptive steps.
