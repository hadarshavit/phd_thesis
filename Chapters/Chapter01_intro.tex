
\chapter{Introduction}\label{ch:ch01:introduction}


\Gls{ai} has made substantial progress in recent decades, both in research and in practice.
Modern \gls{ai} methods solve problems across a growing range of domains: they classify images, process natural language, support automated reasoning, verify hardware and software systems, and search for high-quality solutions to difficult optimisation problems.
This diversity is important for the perspective taken in this dissertation.
\Gls{ai} is not a single algorithmic technology, but a broad collection of methods whose behaviour depends strongly on the problem instances, data sets, configurations, and computational budgets to which they are applied.


A common feature of these settings is that there are usually many candidate algorithms, and each algorithm often has many hyperparameters that control its behaviour.
Moreover, the performance of these algorithms can vary significantly across different instances and configurations.
An algorithm that is performs well on one instance may be weak on another, a configuration that works well for one data set may fail on a different one, and stochastic algorithms may behave differently across repeated runs on the same input.
These performance variabilities are challenging to model and predict, however, they provide an opportunity to select and configure the best algorithm for a given task.

Empirical performance prediction is predicting the performance of algorithms on unseen problem instances, configurations, or combinations of both.
In automated algorithm selection, such predictions support choosing an algorithm for a given instance.
In automated algorithm configuration and hyperparameter optimisation, they support searching for high-performing configurations.
In explainability-oriented settings, they support understanding which instance properties, configuration choices, or regions of the search space drive algorithm behaviour.
Although these uses differ in detail, they share the same underlying question: how can we learn useful models of algorithm performance from empirical observations?

Despite the success of empirical performance prediction, these methods are still difficult to use robustly in many settings.
High-quality instance features may be expensive to compute or unavailable, predictive models may not be accurate enough in the parts of the space that matter for decision making and even when predictions are accurate, they may be hard to interpret or deploy in real-world applications.
This dissertation studies empirical performance prediction through these connected limitations and develops methods, benchmarks, and tools that make performance prediction more useful in practice.

\section{Challenges in the field}

\subsection{Features are hard to extract, expensive and not always available}

When empirical performance prediction is applied across problem instances, as in automated algorithm selection and many configuration techniques, a crucial first step is to represent each instance through descriptive numerical features.
However, extracting high-quality features in practice can be slow, brittle, or impossible for large modern instances.
Early in this work, we observed this problem in the Boolean satisfiability problem (\gls{sat}), a domain in which empirical performance prediction has been used for many years.
The widely used SATzilla feature extraction pipeline had become difficult to apply to contemporary \gls{sat} instances because solvers, preprocessors, instance sizes, and computing systems had changed substantially since the original implementation.
This creates a direct bottleneck: if the features cannot be computed reliably, downstream performance prediction, algorithm selection, and explainability cannot be used reliably either.

Feature representation also matters in high-dimensional optimisation and machine learning settings.
Many real-world problems are high-dimensional, which can lead to severe scalability and performance degradation.
In black-box optimisation, the volume of the search space grows quickly with dimensionality, making useful observations sparse and locating high-performing solutions expensive.
Dimensionality reduction is one way to alleviate this problem by projecting high-dimensional spaces onto lower-dimensional representations.
However, many dimensionality reduction methods were originally designed and evaluated for classical machine learning tasks, such as clustering or classification.
It is therefore not obvious whether they preserve the aspects of the search space that matter for optimisation, where target values and landscape geometry can be more important than global variance.
This motivates a task-driven view of representation quality.

\subsection{Models are not accurate enough}

Even with informative features, the predictive models and surrogate models used in algorithm selection, configuration, and Bayesian optimisation must be accurate enough to guide decisions effectively.
Standard modelling approaches face several difficulties.
Tabular empirical performance models depend heavily on hand-crafted features, which may fail to capture the global structure of complex objects such as Boolean formulae.
Algorithmic performance, especially for randomised solvers, is often stochastic, so a single scalar target can hide important variation between runs.
Performance data can also be right-censored when solvers are stopped at a cutoff time, which makes the true runtime of unsolved instances unknown.

In Bayesian optimisation, the role of accuracy is even more subtle.
Different surrogate models, such as Gaussian processes, random forests, and gradient-boosted trees, have complementary strengths depending on the search space and the phase of the optimisation trajectory.
Choosing one surrogate model statically can therefore be limiting.
Moreover, traditional machine learning metrics such as global mean squared error do not necessarily explain optimisation success.
A surrogate model does not need to be uniformly accurate everywhere; rather, it needs to be accurate in the regions where prediction errors can mislead the acquisition function.
Understanding where accuracy matters is therefore central to designing better model-based optimisation methods.

\subsection{Hard to use existing methods and to gain insights}

Finally, even when features can be computed and models are accurate, using empirical performance prediction in practical workflows and extracting scientific insight from it remain difficult.
The algorithm selection and configuration communities have historically developed domain-specific tools in isolation, leading to separate pipelines for \gls{sat} solving, automated planning, machine learning, and black-box optimisation.
The lack of a unified, problem-agnostic software interface makes it harder to apply methods across domains, compare them fairly, and reproduce results.

There is also an explainability barrier.
Most empirical performance models predict a single statistic, such as mean runtime, and therefore treat algorithm performance as if it were deterministic.
For randomised algorithms, this misses run-to-run variation that may be crucial in risk-sensitive settings.
Distributional performance models can capture this variation, but explaining their predictions is not straightforward.
Standard explainability techniques are designed for scalar-valued predictions and cannot be applied directly to raw distribution parameters in a way that is immediately meaningful.
To gain insight, distribution predictions need to be connected to interpretable statistics such as mean, variance, skewness, and tail behaviour.

\section{Contributions of this thesis}

This dissertation is organised around three connected questions.
First, how can we obtain better representations of problem instances and search spaces?
Second, how can we build better predictive models and surrogate models once those representations are available?
Third, how can we make the resulting methods easier to understand, compare, and use?
The chapters answer these questions in sequence.

% \subsection{Contributions by thesis part}

\subsection{Better Features}

The first part of the dissertation focuses on the representations that make empirical performance prediction possible.
\cref{ch:ch03:rev_SATzilla}, based on
\begin{itemize}
    \item \fullcite{ShaHoo24}
\end{itemize}
contributes a modernised feature extraction tool that replaces outdated preprocessors and solvers, resolves compilation and memory issues encountered on contemporary \gls{sat} instances, and introduces a configurable feature computation timeout.
The chapter shows that this infrastructure work is not merely engineering maintenance: updating the feature extractor leads to better downstream performance in satisfiability prediction, runtime prediction, and automated algorithm selection.
In this sense, the chapter establishes a central theme of the dissertation: better empirical performance prediction often begins with making the inputs to the model reliable and informative.

\cref{ch:ch04:dim_red}, based on
\begin{itemize}
    \item \fullcite{ShaEtAl25}
\end{itemize}
contributes a systematic benchmark of dimensionality reduction methods across machine learning and black-box optimisation tasks.
Rather than judging dimensionality reduction only by generic reconstruction or variance-preservation criteria, the chapter evaluates whether reduced representations preserve the information needed for specific downstream tasks.
The results show strong performance complementarity: methods that work well for one task, dimensionality, or data regime may be poor choices for another.
This makes dimensionality reduction itself an algorithm selection problem and motivates task-aware representation choices.

\cref{ch:ch05:dymbo}, based on
\begin{itemize}
    \item \fullcite{ShaEtAl25b}
\end{itemize}
connects representation quality to model-based optimisation.
Although the chapter primarily develops a modelling method, it appears in this part because its central mechanism depends on representing the changing suitability of surrogate models during an optimisation run.
DyMBO contributes a dynamic ensembling strategy that evaluates the recent ranking quality of candidate surrogate models and uses a memory-aware exponential moving average to update their weights.
The resulting optimiser adapts to different search phases and improves over static surrogate choices and competing hyperparameter optimisation frameworks.
Together with the preceding chapters, this shows that empirical performance prediction benefits not only from better instance features, but also from better representations of which modelling assumptions are appropriate at a given moment.

\subsection{Better Models}

The second part turns from representation to predictive modelling.
\cref{ch:ch06:gnns_epms}, based on
\begin{itemize}
    \item \fullcite{ShaHoo25b}
\end{itemize}
contributes a benchmark for graph-based \gls{sat} empirical performance prediction and compares multiple graph representations and neural architectures against standard tabular models trained on hand-crafted SATzilla features.
Its main contribution is to show that learned graph representations can be competitive for performance prediction and algorithm selection, and can in some settings outperform hand-crafted features.
This provides a complementary answer to the feature-engineering work in \cref{ch:ch03:rev_SATzilla}: instead of only improving hand-crafted features, we can also learn representations from the structure of the instance itself.

The automated machine learning chapter studies empirical performance prediction in automated machine learning.
Its role in the thesis is to connect the algorithm selection and optimisation themes to machine learning pipelines, where the objects being selected are not solvers for a single combinatorial problem but learning algorithms and their configurations.
This chapter strengthens the cross-domain argument of the dissertation: the same core difficulties of representation, prediction, and decision making appear in \gls{sat}, black-box optimisation, and automated machine learning, even though the data structures and performance measures differ.

\cref{ch:ch08:noisy_oracle}, based on
\begin{itemize}
    \item \fullcite{ShaHoo25}
\end{itemize}
contributes a noisy-oracle framework that systematically controls prediction error across the search space, making it possible to isolate the effect of localised surrogate accuracy from other modelling confounders.
The empirical and theoretical results show that accuracy in regions with good objective values is more important than accuracy defined purely by distance to the optimum.
This gives a more precise design principle for surrogate modelling: models should not simply minimise global error, but should avoid errors that make poor or merely competitive regions appear better than they are.

\subsection{Better Insights}

The third part addresses the interpretability and usability of empirical performance prediction.
\cref{sec:ch09:dist_explain}, based on
\begin{itemize}
    \item \fullcite{ShaHoo25c}
\end{itemize}
contributes a framework for predicting and explaining full runtime distributions of randomised algorithms.
It introduces a tree-based XGBoost approach for parametric distribution prediction and explains the resulting distributions through interpretable statistics such as mean, variance, interquartile range, skewness, and kurtosis.
This makes it possible to identify which instance features affect the scale of algorithm performance and which affect the shape and tail behaviour of the distribution.
The chapter therefore extends empirical performance prediction from asking only how long an algorithm is expected to run to asking how uncertain, variable, and risky its behaviour may be.

\cref{ch:ch10:asf}, based on
\begin{itemize}
    \item \fullcite{ShaHoo25d}
\end{itemize}
contributes a unified, problem-agnostic Python library for building, benchmarking, and deploying algorithm selection pipelines.
ASF provides modular components for selection, pre-selection, pre-solving, feature processing, and automated configuration, and validates these components through case studies in machine learning and artificial intelligence.
This final contribution turns the methodological work of the thesis into reusable infrastructure: empirical performance prediction becomes easier to apply outside the narrow domain in which a method was originally developed.

\section{Structure of the dissertation}

The order of the dissertation follows the dependency structure of empirical performance prediction.
Part~I introduces the necessary background on algorithm selection, Bayesian optimisation, and related concepts.
Part~II, \emph{Better Features}, starts with the inputs to performance models: reliable hand-crafted features, task-aware dimensionality reduction, and adaptive information about which surrogate models are appropriate during optimisation.
Part~III, \emph{Better Models}, then studies how to improve the models themselves, from graph neural empirical performance models to surrogate models whose accuracy is aligned with optimisation performance.
Part~IV, \emph{Better Insights}, asks how these methods can be explained and used more broadly, through distribution-level explanations and reusable algorithm selection software.
Finally, Part~V synthesises the results and discusses how the contributions fit together into a broader view of empirical performance prediction as a practical tool for building more adaptive \gls{ai} systems.
